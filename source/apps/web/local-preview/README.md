## 当前交互

- 宽屏每行最多5张卡片，小屏自适应。列表图片16:9，小幅内边距；单图/叠卡统一，卡片轻微悬停上浮，后层散开，移开收回。
- 添加主体在右上角；无搜索/配音状态筛选行。配音唯一入口进入同一主体弹窗。
- 左侧大图、形象缩略图；名称悬浮显示。右侧提示词与图片版本并列；模型、版本列、底部上传/生成按钮左右对齐。
- 点版本即应用，无额外“应用此图”步骤；“用作参考”累加多张参考图，去重，可逐张移除；添加参考是方形虚线控件。
- 新增/编辑使用一致结构，新增支持名称/类型、生成图片/上传成品及预览。
- 配音包括声音库/设计/克隆；选中态清晰。设计只保留自定义描述、声音名称、展开的试听台词；选择当前形象/整个角色的应用范围。
- 声音库卡片试听按钮固定底部，名称换行不影响对齐。

## 功能边界

图片版本应用、声音绑定/解绑只保存在浏览器localStorage，不修改线上项目。提示词草稿也仅本地保存。参考文件可选择、压缩、预览；参考列表在弹窗关闭后释放。

真实生成、成品上传、主体创建/导入、设计声音/克隆及生成试听结果未接入本地服务；请求返回明确501提示，无伪造结果。图片/音频预览依赖网络。

多参考图源码链路：FormData重复`referenceImages` → server上传/队列`referenceImageUrls` → worker/SDK `imageUrls`。单张仍兼容旧`parentImage`/`imageUrl`。外部服务是否接受复数契约尚未联调确认，不能据此宣称生产支持。

## 工程交接

`local-preview`的API是模拟器，不可带入生产；B/focus样式和布局context目前挂在本地入口。正式迁移需将选定样式/context接入项目组件，再联调鉴权、真实数据、上传/生成与队列/provider契约。使用交接包`source-overlay/`及`changes.patch`核对，先在独立分支应用，勿直接覆盖正在修改的文件。

阶段门禁及浏览器证据位于`specs/plans/`与`apps/web/evidence/`；当前布局、选中即用、多参考图、悬停及试听对齐均已通过相应冻结门禁。交接包说明列出精确边界与复现流程。
